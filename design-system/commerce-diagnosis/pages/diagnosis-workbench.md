# 诊断工作台页面规则

本页在 `MASTER.md` 的颜色、间距、对比度和交互规则上使用产品工作流，而非其中的 Enterprise Gateway 营销页模板。

## 信息层级

1. 顶部始终明确“诊断工作台”为主功能，“算法实验”为第二部分。
2. 首屏展示数据导入、来源声明、预检状态和“开始诊断”操作；空状态给出示例数据入口，并醒目标明“合成数据”。
3. 数据通过预检后，显示店铺、SKU、基线/异常日期窗、六项指标的覆盖率及冲突数；失败时给出具体可操作的修复提示。
4. 任务提交后展示排队/运行/完成/失败，完成后依次显示销售变化与趋势、候选原因、支持与反对证据、证据缺口、只读经营建议及报告下载。
5. 任务历史显示数据来源声明与运行状态，避免把合成数据案例与实际导入混淆。

## 图表与可访问性

- 销量、访客、库存等连续逐日指标用折线或小倍图；基线与异常窗口清晰标注。
- 趋势图必须有文字概述和可读的逐日数据表。缺失、冲突、异常通过文字或形状补充表达，不只靠颜色。
- 上传、预检、提交有明确加载、成功、失败反馈；错误提示保留输入且说明如何修复。
- 所有交互提供标签、可见焦点和键盘访问，触控目标至少 44px；尊重 `prefers-reduced-motion`。
